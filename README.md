# Human Resource Data Analysis (Interactive Dashboard using by Excel)
## Project Objective
The Manager of company wants a detailed report from human resource department about the company, its departments, and employees.
## Dataset Used
- <a href="https://github.com/datasctraveller/hr-workforce-dashboard/blob/main/hr_dataset_300_unique_names.xlsx">Hr Dataset </a>
## Questions (KPIs)
- How many workers are there in the company?
- How many active workers are there in the company?
- How many separated workers are there in the company?
- What are the names of top 10 highest-paid employees in the company?
- How many active workers are there in each department?
- Demonstrate the average performance score for each department.
- Demostrate attrition count by gender and age group.
- Demostrate attrition count by gender and department.
- What is the average salary for  each department in the company?
- Compare employee salaries by gender and jobtitle.
- what is the average salary of high performering workers by department?
